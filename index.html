How this works

City-wide air quality monitors are too sparse to catch localized events — a burning pile in one lane, a smoky stretch of road. AirWatch lets residents flag what they see, uses Gemini's vision model to classify each photo, and groups nearby reports into hotspots.

Authorities get a triage view ranked by severity, and Gemini can draft a short advisory for any hotspot in one click.

Before you deploy

This prototype calls the Gemini API directly from the browser. Add your own API key below to enable photo analysis, forecasts, and advisories.
